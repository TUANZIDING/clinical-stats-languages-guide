反复测量 / 多中心混合模型 / GEE 等相关结构、模型含义、缺失
常见误区 / A

“不正态，就换非参数。”

先看目标量、设计、图形和异常值。秩方法也有条件，未必回答均值差的问题。

常见误区 / B

“不显著，就是没有差异。”

看效应估计与 CI 的精度。等效与非劣效需要预定界值和专门设计。

常见误区 / C

“数据有 100 行，n 就是 100。”

同一患者的多次记录有关联。先数独立研究对象，再理解重复信息。

这是一份演示性估计。解释时要同时看差异、区间宽度与设计；P 值不说明临床意义。真实研究的样本量、基线调整和缺失处理需要预先设计。

看看 R 和 Python 的关键指令
R / 基础 stats
# A−B；双侧；不假设等方差
t.test(a, b,
       var.equal = FALSE,
       alternative = "two.sided",
       conf.level = 0.95)
Python / SciPy
# 明确覆盖等方差的默认参数
result = stats.ttest_ind(
    a, b, equal_var=False,
    alternative="two-sided",
    nan_policy="raise")
result.confidence_interval(0.95)

这两段是关键指令；完整数据读入、检查和输出脚本位于仓库 examples/。SAS 示例与 C++（需 Boost）也使用同一数据和方向。运行验证状态见仓库 VALIDATION.md。

分布与方差检查：提供线索，不自动换方法

先看独立性、目标量、原始分布与极端值。Shapiro P>0.05 不证明正态；Levene P>0.05 不证明方差相等。Welch 不要求等方差，仍有适用条件。偏态不自动等于“必须换秩检验”。
