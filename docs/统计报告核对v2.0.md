# 统计报告核对 v2.0

这份清单用于讨论与人工复核，不颁发“合规”或“可以投稿”结论。统计报告按 [SAMPL](https://www.equator-network.org/reporting-guidelines/sampl/) 核查；研究设计还需相应报告指南。勾选清单不是独立统计审核。

| 核对项 | 必须能回答 | 不能用什么代替 |
|---|---|---|
| 设计与目标量 | 谁、何时、什么设计、估计什么量？ | 软件名称或“AI 推荐” |
| 独立分析单位 | n 是患者/动物/供者，还是孔、图像、重复测量？ | CSV 行数 |
| 主要结局 | 变量、单位、时间点、方向、主次分析是否预设？ | 挑一个显著变量 |
| 样本数 | 原始数、各变量已知数、各分析数和排除原因？ | 图里点数或统一总 n |
| Table 1 | 基线与随访分开、类别分母、SD/IQR 与缺失数？ | 自动加 P 值或自动筛协变量 |
| 方法参数 | 独立/配对、双/单侧、方差、链接、相关结构？ | 包默认值 |
| 条件与异常值 | 原始图形、诊断、极端值来源、排除规则与数量？ | 一个正态性 P 值 |
| 缺失 | 发生位置、原因、处理依据、假设与敏感性分析？ | 自动删除所有 NA 或均值填补 |
| 调整与多重性 | 协变量依据、比较家族、主次结果、校正方式？ | Table 1 显著性或逐个试方法 |
| 结果与解释 | 效应量、单位、CI、精确 P、设计限定解释？ | 星号、“无效”或“证实机制” |
| 图注 | 点代表谁、各组 n、误差线/箱须定义、方法？ | 只写“均值 ± 误差” |
| 复现与审核 | 数据版本、代码、软件、日志、审核人/日期？ | 跨语言数值一致即认定方法正确 |

## 真实研究报告框架

以下待填字段必须由作者/团队提供，不能让 AI 补造：

> 研究采用【AUTHOR_INPUT_NEEDED：设计】，分析单位为【独立单位】。主要结局为【变量、单位、时间点】，目标量为【量与方向】。按【方案版本/预设情况】使用【方法及明确参数】，调整【协变量及依据】。原始 n=【】，该分析 n=【】，排除【数量与原因】。缺失采用【方法、理由与假设】，诊断和敏感性分析为【】。多重性处理为【比较家族与方案】。使用【软件/包/版本】；统计方案由【人员/日期】确认。

> 【组别】的结局汇总为【估计与变异】，效应【量、单位、方向】为【数值】，95% CI【】、【精确 P】。结合【设计与有依据的临床阈值】解释；【限制与不确定性】。不显著不能证明等效；关联不能自动写成因果。

方法段、结果段、Table 1、图注和代码须互相一致。修改缺失规则、分析人群、比较方向或方法后，重新生成结果并记录方案变更，不手工改数值。探索性和预设分析应区分；没有验证真实数据前不填写已完成状态。
