# 先问研究问题，再选统计方法

## 1. 方法、软件、语言是三个层次

**统计方法**是处理研究问题的规则，例如 Welch t 检验、Logistic 回归。**软件**是执行这些规则的工具，例如 SAS、SPSS、jamovi。**语言**用于表达计算步骤，例如 R、Python、C++。R 同时是一种语言和统计计算环境；SAS 是分析软件体系，也有自己的编程语言。

“我用 R”没有说明方法；“我做回归”没有说明结局、模型、调整变量和目标量。

## 2. 先写一句完整的问题

模板：在【研究人群】中，在【设计与时间范围】下，我希望【描述/比较/关联/预测/因果】，结局是【定义与单位】，目标量是【均值差、风险差、其他】，分析单位是【患者/配对/中心等】。

例如：“在一个假设的随机分组研究中，比较两组患者固定时间点的收缩压，估计 A−B 的平均差，每位患者一个结局值。”这才有讨论两独立样本均值方法的基础。

观察性研究比较治疗组时，即使 P 很小，也不能自动解释为治疗导致了差异。预测问题关心新患者上的表现；关联问题关心变量关系，两者不能只凭同一个回归表互换结论。

## 3. 五类目标

| 目标 | 要回答的问题 | 先关注什么 |
|---|---|---|
| 描述 | 这些人的数据是什么样？ | 分母、缺失、分布、区间估计 |
| 比较 | 两组或多个时间点有什么差异？ | 设计、目标量、配对与独立性 |
| 关联 | 某变量与结局有怎样的关系？ | 关系形状、混杂、模型解释 |
| 预测 | 对新患者的预测可靠吗？ | 数据划分、泄漏、校准、验证 |
| 因果 | 如果改变干预，结局会怎样？ | 时间零点、分配机制、因果假设 |

最后两类需要完整设计，网页不会给出“一键最优模型”。

## 4. 候选方法地图

下面是**教学起点**，不是自动处方。每一项均需要确认目标量、条件、缺失与分析计划。

| 场景 | 候选方法 | 应报告或讨论的量 | 必须检查 |
|---|---|---|---|
| 两独立组，连续结局，关注均值差 | Welch t 检验 | 均值差及 CI | 独立性、分布与异常值；小样本时分布假设尤其重要 |
| 同一人两次连续测量 | 配对 t 检验；满足相应条件时考虑符号秩方法 | 配对差的均值或适合秩方法的目标量及 CI | 配对是否正确；检查差值分布，而非仅检查两列原始值 |
| 三个及以上独立组连续结局 | 单因素 ANOVA / Welch ANOVA；适合时用 Kruskal–Wallis | 预定组间对比及 CI | 残差与方差条件；事后比较的多重性 |
| 两独立组二分类结局 | 2×2 卡方检验或 Fisher 精确检验 | 风险差、风险比、优势比等适合设计的量及 CI | 期望频数、抽样设计；病例对照研究不能直接由抽样比例估计风险 |
| 同一人两次二分类结果 | McNemar 检验；不一致对很少时讨论精确形式 | 配对比例变化及 CI | 关注不一致配对，不能当成独立 2×2 表 |
| 三个及以上组二分类 / 无序多分类 | 列联表方法；需调整时考虑适合结局的回归 | 各类概率与预定对比 | 稀疏单元格、组数、模型参数与多重比较 |
| 有序等级结局 | 合适的秩方法或有序回归 | 等级分布 / 适当模型效应 | 等级含义、比例优势等模型假设；不要随意当连续变量 |
| 计数结局 | Poisson / 负二项等模型 | 计数率或发生率比及 CI | 暴露时间 offset、过度离散、零值机制 |
| 连续结局与解释变量 | 线性回归；必要时选择合适的替代模型 | 回归系数及 CI | 关系形状、残差、异常值；不是要求所有变量都正态 |
| 二分类结局与解释变量 | Logistic 回归；按目标量讨论其他二项模型 | OR 或目标量对应的估计及 CI | 事件数、稀疏性、分离、预定调整；OR 不等同 RR |
| 事件时间，有删失 | Kaplan–Meier 描述；合适时用 log-rank / Cox | 时间点生存率或 HR 等及 CI | 删失、随访、比例风险、竞争风险；HR 不是风险比 |
| 多个时间点 / 多中心聚类 | 混合模型 / GEE 等 | 依模型定义的效应及 CI | 相关结构、时间、中心数、缺失；模型含义不同 |
| 两个连续变量之间的关系 | Pearson / Spearman 或回归 | 相关系数或模型效应及 CI | 线性/单调性、异常值、独立性；相关不是因果 |

基础实现依据：[R t.test](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/t.test.html)、[R oneway.test](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/oneway.test.html)、[R Fisher](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/fisher.test.html)、[R McNemar](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/mcnemar.test.html)、[R GLM](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/glm.html)、[Cox](https://stat.ethz.ch/R-manual/R-devel/library/survival/html/coxph.html)、[GEE](https://www.statsmodels.org/stable/gee.html)。完整来源说明见 [sources.md](sources.md)。

## 5. 不要只做“正态检验 → 选方法”

正态性检验的 P 值不能独自决定方法。先考虑目标量、独立性、设计、样本量、图形、异常值及方法的稳健性。样本量很大时，轻微偏离也可能得到很小的正态性检验 P；样本量很小时，不显著不能证明正态。

Welch 方法不要求两组方差相等，但没有解决重复测量、混杂、严重异常值或所有小样本分布问题。[NIST 两样本 t 检验](https://www.itl.nist.gov/div898/handbook/eda/section3/eda353.htm)

Mann–Whitney / Wilcoxon 秩和检验一般比较分布或秩的相对位置；额外的分布形状条件满足时，才可作特定位置差解释。它不是通用的“中位数检验”，也不能修复不独立的样本。[R Wilcoxon 文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/wilcox.test.html)

## 6. 样本量、缺失和混杂不能事后补一句

- **样本量**：研究前根据目标量、临床意义、变异或事件率、精度/功效和设计计算。不要将“事后功效”作为不显著结果的解释依据。
- **缺失**：列出各变量和各组的缺失数量、原因及时间结构；完整病例分析和多重插补都需要假设。插补、删行、填 0 都不是无条件默认选项。
- **混杂**：观察性研究根据研究问题、领域知识和时间顺序决定调整变量。不要仅根据单因素 P<0.05 筛选，也不要把中介和碰撞变量机械加入模型。
- **多重性**：预定主要结局、主要对比和必要的校正。不能反复尝试检验直到显著。
- **复杂设计**：匹配病例对照、集群随机、复杂抽样、非劣效、交叉试验等应单独设计；本简化向导不覆盖这些专门方案。

这些是形成分析计划的检查项，不能通过网页选择框完成识别或假设验证。

## 7. 三个临床情境练习

**固定随访点两组数值比较**：先确认结局定义、随机或观察性设计、基线值和失访。如果目标是未调整均值差且观测独立，Welch 可作候选；若要调整基线或其他变量，讨论回归/ANCOVA。两组分别“前后显著/不显著”不能证明组间变化有差异。

**同一患者干预前后阳性率**：配对二分类，候选是 McNemar；独立卡方忽略了配对信息。若只有前后总阳性人数、没有逐对关系，无法得到所需不一致对信息。

**一年死亡结局**：如果人人都完整随访一年，可以讨论一年风险的二分类模型；如果随访时长不同或有删失，则不能只按最终“死/活”使用普通 Logistic，需讨论事件时间方法。

## 8. 解释结果

P 值不表示“原假设为真的概率”，也不表示临床重要程度。P≥0.05 不等于两组相同；等效与非劣效需要预先定义界值和专门设计。频率学 95% CI 的含义是：在相同抽样与分析条件下反复构造区间，约 95% 的区间覆盖固定的真值，不能把它直接解释为此次区间含真值的概率。[ASA 声明](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf)

按问题报告效应量、CI、样本量/事件数、方法、参数设置、缺失处理与限制。把探索性分析标为探索性。[SAMPL](https://www.equator-network.org/wp-content/uploads/2013/07/SAMPL-Guidelines-6-27-13.pdf)
