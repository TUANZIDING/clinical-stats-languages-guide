# 医学科研初学者的软件路线

## 可以零编程起步，但统计概念仍需要学习

先学会识别变量、独立与配对、目标量、效应量和置信区间，再选择合适界面。菜单操作能降低输入代码的门槛；保存数据、分析设置和输出仍是复现的一部分。

## 比较的是角色，不是排行榜

| 工具 | 它是什么 | 编程门槛与界面 | 常见学习用途 | 获取与费用边界 |
|---|---|---|---|---|
| jamovi | 基于 R 的统计软件 | 图形界面，可查看分析语法 | 常规统计入门 | 桌面版免费开源；云服务条款另查 |
| SPSS | 商业统计软件 | 菜单为主，也支持语法 | 课程和常规分析 | 按机构许可/产品方案核对费用 |
| R | 语言和统计计算环境 | 基础脚本起步；可配编辑器 | 医学统计、绘图、可复现分析 | R 免费开源；附加服务可能收费 |
| Python | 通用编程语言 | 脚本与 notebook；统计依赖库 | 数据处理、统计、影像、机器学习 | Python 免费；计算资源/服务另计 |
| SAS | 分析软件体系和编程语言 | SAS Studio 等界面；支持程序与任务 | 团队化分析和统计编程 | 商业授权；OnDemand for Academics 有免费学习入口，按其许可使用 |
| C++ | 通用编译语言 | 编译与依赖管理要求较高 | 高性能算法、统计库开发 | 工具链和库许可各自核对 |

依据：[jamovi](https://www.jamovi.org/)、[R](https://www.r-project.org/about.html)、[Python](https://www.python.org/doc/essays/blurb/)、[SAS OnDemand](https://www.sas.com/en_us/software/on-demand-for-academics.html)。SPSS 的价格和具体许可未在本项目比较，不提供报价。

## 给临床科研人员的条件化建议

1. **完全不想写代码，先把概念学清楚**：可从 jamovi 或机构已有 SPSS 开始，完成一个模拟两组比较并保存分析设置。
2. **准备长期做科研、愿意逐步学代码**：可从 R 学起。先会读 CSV、画图、做一个指定的模型和保存输出，而不是背全部语法。
3. **方向偏影像、AI 或自动化**：Python 是可考虑的学习路线，仍需另外学习统计推断；会训练分类器不等于会设计医学研究。
4. **课程、导师或团队使用 SAS**：优先衔接现有流程，再视需要学 R 或 Python。SAS 的免费学习入口不等于任意用途都可免费使用。
5. **C++**：除非研究任务涉及算法工程或已有代码库，通常可延后。它可以计算 P 值，例如 [Boost Math 的 t 分布](https://live.boost.org/doc/libs/1_51_0/libs/math/doc/sf_and_dist/html/math_toolkit/dist/dist_ref/dists/students_t_dist.html)；“C++ 算不出 P 值”不成立。

以上是根据工具角色和教学任务提出的**路线建议**。本项目没有测量初学者学习时间，也不提供雷达评分或固定代码行数排名。

## 30 分钟起步任务

| 阶段 | 做什么 | 完成标志 |
|---|---|---|
| 0–5 分钟 | 区分方法、软件、语言 | 能解释“Welch t 检验”和“R”的关系 |
| 5–10 分钟 | 看变量字典与模拟数据 | 知道一行是一个独立观测，group 是分组 |
| 10–20 分钟 | 用 R/Python 示例或 jamovi 完成教学分析 | 找到 A−B 均值差、CI 和 P |
| 20–30 分钟 | 改写 AI 提问模板、解释结果 | 能说出假设、目标量及不能得出的结论 |

时间只是教学安排，不是经验证的学习效果承诺。后续按自己的节奏学习数据清洗、回归、缺失、验证及研究设计。

## 用同一任务判断工具

本项目四个示例使用相同教学数据和同一双侧 Welch t 检验。重点是分组顺序、缺失规则、方差假设与结果一致性，而非谁写得短。R 的 `t.test` 默认不假设等方差；SciPy 的 `ttest_ind` 默认假设等方差，需要显式传 `equal_var=False`。[R 文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/t.test.html)、[SciPy 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_ind.html)
