## 怎样验证

1. 从全文提取设计、分析单位、变量定义、缺失编码、权重、调整集与目标量。
2. 把设计事实输入向导，检查是否遗漏决定方法的重要信息；文章用过的方法本身仍需审查。
3. 独立抄录论文对照点并冻结；不能从自己的输出生成“预期答案”。
4. 从 CDC 获取原始 public-use XPT，校验格式、唯一 ID、来源与 SHA-256。
5. 使用自己的小范围实现复算，比较人数、方向、效应、区间和明确的舍入容差，记录不一致及原因。

本次没有执行第三方 R Markdown，也没有把其未明确授权的代码复制进 MIT 仓库。仅检查固定提交，自己的实现注明参考出处。公开患者级记录保存在忽略的 `build/`，仓库只保留代码、来源清单和汇总结果。

## 实际对照结果

近视案例采用每位参与者右眼，保留论文的排除顺序，按作者模型调整年龄、性别与调查周期；组件权重与分层/PSU 都进入设计。

| 对照项 | 论文 | 本次复算 |
|---|---|---|
| 分析人数 | 19,756 | 19,756 |
| 五个教育组人数 | 2,457 / 3,275 / 4,805 / 5,397 / 3,822 | 完全一致 |
| 大学及以上 vs 未到九年级：调整后的连续结局差，D | −1.47，95% CI [−1.63, −1.30] | −1.465725，正态 Wald CI [−1.626809, −1.304641] |
| 同一对比：调整后近视 OR | 3.74，95% CI [3.12, 4.48] | 3.739930，正态 Wald CI [3.122603, 4.479300] |

72 个点包含 5 个样本流程数字、15 个描述数字、4 个模型人数、16 个效应及 32 个 CI 端点。人数必须完全相等，两位小数的容差是 0.0050001，一位小数百分比为 0.0500001。P 值、其余模型、所有图与补充表未纳入本次数值通过判据。

**版本差异单独保留。** 论文 survey 3.34 的 `confint.svyglm` 默认 `ddf=Inf`，采用正态 Wald 区间，已从[官方 CRAN 源码归档](https://cran.r-project.org/src/contrib/Archive/survey/survey_3.34.tar.gz)核查。当前 survey 的默认 t 区间中，16/32 个端点与论文两位小数一致，另 16 个不同。不能把当前默认输出宣称为全数一致，也不能仅为了匹配数字随意换算法。

初次实现遗漏手术问卷编码 9 的缺失转换，得到 19,781 人；与作者源码及变量说明对照后修正为 19,756 人。这个错误说明：正常运行不能代替验证。当前脚本同时保留按原文筛选后建调查设计的复现，以及先建完整设计再定义 domain 的敏感性输出；实际新研究遵循 [CDC 方差与子人群教程](https://wwwn.cdc.gov/nchs/nhanes/tutorials/varianceestimation.aspx)。

结果在[汇总输出](../data/paper-replayv2.1.json)、[72 点逐项核对](../data/paper-checkv2.1.json)和[冻结目标](../data/paper-targetsv2.1.json)。

## 对项目的改进

向导新增“抽样设计”，复杂调查明确提醒组件权重、跨周期合并、分层、PSU、方差、domain 与样本人数/总体估计的区别，并讨论调查加权模型。抽样未知时不默认为普通样本。

四个文献输入案例及五个边界检查成为回归测试，防止以后退回普通 Welch / 普通回归提示。病例都经人工编码且用于修复后回归检查，**不是独立盲测集**，不报告准确率。

已发表不代表每一步无误。例如近视文章的部分族群分析未保留调查结构；出生体重源码将缺失盎司当作 0。两者都不能成为面对任意临床数据的自动规则。

## 自己再运行

在仓库根目录执行。R 的 `survey`、`foreign` 和 `jsonlite` 需从官方 CRAN 安装；这是可选复现路径，通常项目检查保持离线。

```bash
python3 scripts/fetch-nhanesv2.1.py --download
Rscript examples/r/nhanes-replayv2.1.R
python3 scripts/verify-paperv2.1.py --input build/papersv2.1/nhanes-replayv2.1.json
```

下载脚本限定 15 个 CDC 文件，本次共 43,677,040 bytes（约 43.7 MB），包含第二篇所需 ECQ。`data/nhanes-source-manifestv2.1.json` 记录本次来源哈希。重跑需与这些哈希比较；内容变化需调查，不能自动更新期望值。`python3 scripts/verify-paperv2.1.py` 仅核对仓库保存的汇总快照；CI 中通过它不等于服务器重新下载数据并复现原文。

## AI 能做的与仍待验证的

使用[论文核查提示词](../templates/论文核查提示词v2.1.md)，要求 AI 逐项提供原文位置，未知标待补充，再由实际程序复算。上述成功对照是实现验证；本次没有测量任何大模型的回答正确率，也没有取得统计专家签字。正式研究仍需研究设计、混杂、缺失、多重性和解释的人工审核。

用户确认包括 SI 后，三篇论文的正文 PDF、18 个补充文件和出生体重论文的勘误 PDF 均已在本地归档；另保留 3 份 HTML 与 1 份 XML 正文。26 个材料文件共 92,830,207 bytes，逐个记录格式、来源与 SHA-256，见[材料核验清单](../data/paper-materialsv2.1.json)。本地入口为 `build/论文材料v2.1/材料目录v2.1.md`；GitHub 保存来源清单，文章和附件保留在本地。

PDF 检查签名、页数和可提取内容；Nature 的 Reporting Summary 是图像 PDF，已渲染全部三页并目视核查。DOCX 检查 ZIP CRC 与正文 XML，XLSX 检查 ZIP CRC、工作簿、工作表及首行。两份较大的 Excel 首次传输中断，重试/续传完成后才标通过。补充材料取得不意味着补充分析已经复现。
