本次直接实现的是原创 Table 1 / 诊断 / 报告工作流，以及 gtsummary、ggstatsplot 的可选适配。其他资源是学习入口，没有将它们的代码或数据并入项目，也不声称验证其所有功能。

## 建议的学习路径

先理解变量、分析单位、效应和区间，再用本项目离线向导或 jamovi 练习；愿意写代码时学基础 R 的数据读入和 t.test，继而用 gtsummary 明确地生成 Table 1。掌握报告规则后再看 ggstatsplot、回归与生存分析。Python 路线可从现有 SciPy 示例入手；SAS 与团队流程衔接，C++ 作为算法实现学习而非常规入门要求。
