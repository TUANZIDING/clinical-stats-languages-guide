# 统计核查提示词 v2.0

先提供去标识化的设计、变量字典和分析计划。这个模板不会调用 API 或自动上传；不要贴患者标识符、访问密钥或未经授权的原始数据。AI 的建议需要用可核查来源与代码复核。

## 讨论方法与报告

```text
请作为医学统计教学助手，先核对设计和信息缺口，再给候选分析草案。
研究设计：AUTHOR_INPUT_NEEDED
人群、组别、分组/抽样方式：AUTHOR_INPUT_NEEDED
独立分析单位、重复/配对/聚类关系：AUTHOR_INPUT_NEEDED
主要结局、单位、时间点、目标量和比较方向：AUTHOR_INPUT_NEEDED
样本数/事件数及缺失原因：AUTHOR_INPUT_NEEDED
协变量、预设计划、多重比较范围：AUTHOR_INPUT_NEEDED

输出：
1. 列出必须补充的问题；未知处保留 AUTHOR_INPUT_NEEDED，不猜。
2. 给候选方法、适用条件、效应量及 CI 方法；区分诊断与正式结局检验。
3. 不以正态性/方差检验 P 值自动切换方法，不按基线 P 值筛协变量。
4. 核对独立 n、类别百分比分母、缺失、排除、调整、主次比较与图注。
5. 如用秩检验/标准化效应，说明是否仍回答原来的目标量和方向。
6. 只用模拟数据写最小可复现代码，显式指定默认参数，记录版本。
7. 提供可以打开的原始指南/官方文档；区分来源支持和你的推断。
8. 给研究团队需确认的分析计划；不要宣布真实数据已审核或可以投稿。
```

## 交给 Codex 检查本项目

```text
请在 clinical-stats-languages-guide 仓库核查 v2.0 模拟统计实操。
先读 README.md、docs/临床统计实操v2.0.md、data/变量字典v2.0.md
和验证记录v2.0.md。所有新自主命名文件使用 名称+版本号+扩展名，禁止下划线；
不要批量改名既有文件，不覆盖用户未提交更改。

只运行已公开的模拟数据案例，不访问或上传真实患者数据。
运行 npm test、python3 scripts/check_project.py、
python3 tests/clinical-reportv2.0.py、python3 scripts/check-filenamesv2.0.py。
核对核心输出的源文件 SHA-256、Table 1 各变量已知 n / 缺失 n、类别分母、
Q1/Q3 规则、主要结局 n=45/43、A-B 方向、Welch 双侧 95% CI。
确认诊断 P 值不影响主分析选择、基线缺失不触发随访结局的整行删除。

若已安装可选包，运行 examples/r/clinical-tablesv2.0.R；
使用 --plot 时提取并核对 ggstatsplot 内部 t/P，说明标准化效应和 mmHg 均值差的区别。
如无法运行某模块，记录原因和未验证状态，不伪造通过记录。
修复实际问题，更新可复现的验证记录；不手工调数值追求显著。
完成后报告改动、检查结果与未覆盖事项。不要仅因这个提示词发布网页或分析真实数据。
```
