# 研究卡片与方法向导 v2.2 · 第 2 步

2026-10-09。当前是 v2.2 分步开发成果，不代表完整版本或临床统计决策系统已经验证。

## 从哪里开始

打开 [离线网页](index.html)，可选一个教学情境理解填写方式，也可自己填写。先填“问题与目标量”，再展开“分析单位与设计”；数量、时间、缺失与调整依据在第三部分按需填写。所有选择初始留空，隐藏字段不会偷偷采用默认方案。

网页不会上传、调用 AI 或自动持久保存。刷新会丢失当前填写；可主动下载 `研究卡片与方法草案v2.2.md`，下载受限时也会显示可复制的草案文本。修改任一输入会使旧结果、旧提问、旧草案文本和下载按钮失效，重新生成后再导出。生成的 AI 提问包含同一张卡片、候选和缺口，需手动复制到自己的工具。

研究卡片模板在 [templates/研究卡片v2.2.md](../templates/研究卡片v2.2.md)。网页中的文本是研究者填写的声明，不是数据审计证据。

## 目标量如何影响候选

| 输入情境 | 向导怎样处理 |
|---|---|
| 抽样、分析单位、相关结构或目标量未知 | 标待补充，不列匹配的普通独立样本方案 |
| 连续结局、两独立组、未调整均值差 | Welch 与仍保留均值目标的稳健 / 重采样讨论；后者需要额外论证 |
| 同一对象两次连续结局 | 配对差的均值分析；不能把原始两列当独立样本 |
| 配对二分类比例差 | 区分配对比例差 / CI 和 McNemar 零差异检验；需要逐对表与不一致对 |
| RR / 风险差 | 不自动替换成 Logistic 的 OR；按目标讨论二项模型或风险标准化 |
| 病例对照样本直接要求 RR / 风险差 | 标关键设计缺口，不从抽样比例估计总体风险 |
| 中位数或分位数差 | 另设指定分位数的估计；一般秩检验不能自动替代这个目标 |
| 复杂抽样 | 保留权重、分层、PSU、domain、周期规则及设计一致方差；有重复观测时两种结构都要处理 |
| 重复 / 聚类 | 讨论混合模型与 GEE，明确目标层次、相关结构及聚类信息；不套 Welch |
| 稀疏单元格、分离、零事件或零不一致对 | 要求进一步核查可识别性和区间；没有按总事件数设置通用“每变量十个事件”门槛 |
| 预测时点 / 预测窗口未知 | 先补充，不直接挑算法；已填时间也仍需验证设计、泄漏和校准检查 |

不同方法可能估计不同的量。例如 Pearson 与 Spearman 的目标不同，混合模型与 GEE 也需要明确效应解释。Fisher 条件 OR 与其他 OR 估计并不无条件等同。向导只列候选与条件，不承诺某一方法最优。

## 输出与保留的未知

结果包括：候选名称、回答的量、选择依据、适用条件、待补充信息、未执行的诊断步骤、报告要求及可打开核查的来源。缺少问题、人群、具体时间、数量或调整理由时，候选可以作为条件化讨论，但整体标为需要复核；不能把“没有必填缺口”读成“条件已经满足”。

不按正态性 P 值自动换方法，不按单因素 P 值自动选择协变量。缺失不默认为无缺失或完整病例分析。样本数量校验只检查填写整数和明显矛盾，不验证功效、数据真实性、缺失机制或模型拟合。

## 来源与范围

规则实现为本项目原创；没有复制第三方代码、文章或补充材料。来源支持对应原理 / 实现，不是对本项目的认证。

- [NIST 两样本 t 检验](https://www.itl.nist.gov/div898/handbook/eda/section3/eda353.htm)：独立、配对与 Welch 的计算结构。
- [R t.test](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/t.test.html)、[Wilcoxon](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/wilcox.test.html)：均值目标及秩方法解释的区别。
- [R Fisher](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/fisher.test.html)、[GLM](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/glm.html)：精确检验与模型分布 / 链接；参数需明确。
- [CDC 方差与 domain](https://wwwn.cdc.gov/nchs/nhanes/tutorials/varianceestimation.aspx)：复杂调查设计不能被普通样本分析替代。
- [TRIPOD+AI 官方入口](https://www.tripod-statement.org/)及 [scikit-learn 数据泄漏](https://scikit-learn.org/stable/common_pitfalls.html)：预测报告与验证流程；不是 AI 统计选法准确率证据。
- [SAMPL](https://www.equator-network.org/reporting-guidelines/sampl/)：报告具体方法、效应及不确定性、样本信息和复核依据。

## 测试与未覆盖边界

新增案例是人工编写的规则回归检查，覆盖配对、复杂抽样及重复观测叠加、聚类、稀疏事件、非法计数、未知目标、目标不匹配、预测时间缺口、病例对照风险限制、P 值不能自动改变决策、导出与未知保留。测试通过不表示这些设计的真实数据模型已验证。

专门的多层相关结构、非劣效 / 等效、竞争风险、多重插补、因果识别和模型功效仍需完整方案；向导不计算这些分析。没有实际 AI 输出评分或真人学习效果试验。后续步骤中的数值复算、可执行诊断和环境恢复尚未因本步完成。
