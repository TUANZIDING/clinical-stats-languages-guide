# AI 统计选择提问模板

请作为医学统计学习助手。先检查信息是否充分，再讨论候选分析；不要编造样本量、研究设计、数据结果或文献。若关键条件不清楚，请明确标为“待补充”，不要替我猜。

## 我的设计

- 研究问题与研究人群：[填写]
- 目标：描述 / 比较 / 关联 / 预测 / 因果
- 研究设计：随机试验 / 队列 / 病例对照 / 横断面 / 其他
- 目标量及比较方向：[如 A−B 均值差；不要只写 P 值]
- 主要结局定义、类型与单位：[填写]
- 分组、参考组及时间点：[填写]
- 分析单位与相关结构：[独立患者 / 配对 / 重复测量 / 聚类]
- 各组独立样本量、事件数、中心数：[填写；未知则标未知]
- 分布与异常值：[图形和已知情况]
- 缺失或删失：[数量、原因与时间；未知则标未知]
- 预定调整变量及选择依据：[填写]
- 主要/次要分析与多重性安排：[填写]
- 使用工具与版本：[填写]

## 请按顺序回答

1. 复述问题，区分方法、软件和目标量；优先列出必须补充的信息。
2. 给出 1–3 个候选方法。用表格比较它们估计什么、适用条件、局限与所需诊断。
3. 解释独立性、配对、聚类、缺失、样本量/事件数与混杂如何影响选择。
4. 列出效应量、CI、模型诊断和适当的敏感性分析。不要自动填 0、自动删缺失或按单因素 P 值选协变量。
5. 提供可打开核查的官方文档、原始方法论文或指南；不确定的引用标“待核查”。
6. 用人为构造的模拟数据提供可运行教学代码，明确分组顺序、双侧/单侧、假设、缺失规则和版本要求。不要直接分析我的真实数据。
7. 列出如何用另一实现或已知示例复核代码与数值。
8. 最后输出一份待研究团队审核的分析草案，区分已知事实、假设、待核查事项和不能得出的结论。

不要承诺“最优方法”，不要为了得到显著结果变更分析，不要将观察性关联自动解释为因果。
