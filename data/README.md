# 数据字典与来源

`synthetic-independent.csv` 是本项目作者为教学**人为构造**的 24 行数据；没有随机抽样、没有患者、没有来源于临床数据库。

| 字段 | 含义 | 规则 |
|---|---|---|
| id | 模拟对象编号 | S01–S24，唯一，不是患者标识 |
| group | 模拟组别 | A 或 B，各 12 行 |
| value | 模拟连续结局 | 教学数值，未赋予真实生理单位 |

假设每行独立、没有缺失，两组比较的教学目标为 A−B 总体均值差。这里没有真实分配机制，不能从数值推出疗效、临床意义或因果关系。

四种语言读取同一 CSV；绘图和预期结果也从该文件重建。`expected-results.json` 由 `scripts/build_assets.py` 使用 SciPy 计算，作为复核基准。R 和 C++ 可用于独立实现的交叉核对；并不证明分析假设在真实数据中成立。
