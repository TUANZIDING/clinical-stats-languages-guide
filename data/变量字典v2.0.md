# 模拟临床变量字典 v2.0

[synthetic-clinicalv2.0.csv](synthetic-clinicalv2.0.csv) 含 96 个独立模拟对象，A / B 各 48 个。一行一个对象；没有真实患者、来源医院、伦理批件或临床试验注册。样本量只是教学设置，没有功效计算。

| 字段 | 定义 / 单位 | 时点与用途 | 缺失 A / B |
|---|---|---|---|
| id | SIM001–SIM096，唯一模拟编号 | 分析单位核查；不是患者标识符 | 0 / 0 |
| group | A / B，平衡随机打乱的模拟分组 | 分组标签，不是已实施的治疗 | 0 / 0 |
| age | 年龄，岁；正态生成后限制到 20–90 岁 | 基线描述 | 2 / 3 |
| sex | F / M 模拟分类标签 | 基线描述；实际研究需定义性别/社会性别及类别 | 1 / 2 |
| baseline-sbp | 收缩压，mmHg | 基线描述；不作为随访结局 | 2 / 1 |
| baseline-crp | CRP，mg/L；对数正态生成 | 偏态基线描述 | 4 / 3 |
| day28-sbp | 第 28 天收缩压，mmHg | 唯一主要教学结局 | 3 / 5 |

空白单元格表示缺失，0 不是缺失。每个变量在每组内按指定数量随机抽取缺失位置，抽取独立于变量取值。组间缺失比例不同；不能用这种已知的生成过程推断真实研究属于 MCAR / MAR / MNAR。

数据由 [clinical-reportv2.0.py](../scripts/clinical-reportv2.0.py) 生成，NumPy 默认随机数生成器，种子 `20261008`，环境见 [结果 JSON](clinical-resultsv2.0.json)。随访数值由基线值、组别偏移和随机噪声构造；既不是验证的临床模型，也不是任何治疗效果预测。

本案例只比较第 28 天的独立组均值，不把同一对象的基线和随访当作两个独立样本。主要分析只排除随访结局缺失的 8 个对象，不因基线变量缺失额外排除，不插补、不删异常值。Table 1 按每个基线变量分别使用已知记录，类别百分比的分母为该组该变量已知数。具体计划与真实研究迁移限制见 [实操说明](../docs/临床统计实操v2.0.md)。

原来的 [24 行四语言示例](synthetic-independent.csv) 保留，用来验证 R / Python / SAS / C++ 对同一简单问题的参数与结果。
